# Keyboard shortcuts

- **↑ ↓** (or **k j**): move in a menu.
- **Enter**: choose. In the main menu, Run is preselected, so Enter runs the task.
- **← →** (or **h l**), **y**, **n**: answer a yes/no question.
- **/**: filter a long list; **Esc** stops filtering.
- **Ctrl-C** during a sync: finish the current file, then stop. Nothing incomplete is recorded.
